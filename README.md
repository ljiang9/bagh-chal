# 老虎吃羊棋 (bagh-chal)

尼泊尔传统不对称围堵棋 Bagh-chal 的极简实现：5×5 点阵棋盘（含交错对角线），
4 只老虎对 20 只羊。纯 Python 标准库，无第三方依赖。

## 玩法

- **棋盘**：5×5 共 25 个点；横竖线全连，对角线只画在 `(行+列)` 为偶数的格子里
  （标准 Bagh-chal 棋盘的交错对角线）。
- **老虎**：沿线走一格；或跳过相邻的一只羊落到空点，吃掉它。**吃满 5 只羊获胜**。
- **羊**：先逐只布子（共 20 只，老虎每轮也走一步）；布完进入走子阶段，
  每次沿线走一格，不能跳、不能吃。**困死所有老虎（无合法走法）获胜**。

## 用法

```bash
python3 -m bagh_chal                  # 人机交互（需要终端）
python3 -m bagh_chal --auto --games 10 --seed 42   # AI 对 AI 自动演示
```

交互输入坐标都是 `行 列`（0–4）：
- 羊布子：`2 3`
- 走子：`起点行 起点列 落点行 落点列`，如 `0 0 0 1`；跳吃自动执行

## AI 说明

- 老虎：有吃必吃（随机选一只），否则走向离羊群最近的位置。
- 羊布子：模拟布子后老虎的即时跳吃，避开"送吃"位置；兼顾与虎群保持距离以便围堵。
- 羊走子：躲避跳吃威胁（重罚），优先堵住老虎邻格。
- 双方都是 1 步贪心启发式，不做深层搜索。

## 真实验证记录

- `py_compile bagh_chal.py __main__.py`：通过
- 25 项单元测试（`/tmp/test_bagh_chal.py`）：全过
  - 对角线连通性（偶数格相连 / 奇数格不连）、开局四角虎、羊先手
  - 布子合法/被占拒绝/越界拒绝
  - 老虎正交跳吃、**对角跳吃**、跳吃后羊移除+计数
  - 老虎被四面包围判羊胜、吃满 5 只判虎胜
  - 羊走两格/走对方子/错轮次全部抛 `ValueError`
  - AI 布子合法且同种子可复现
- `--auto --games 10 --seed 42`：虎胜 9 / 羊胜 1 / 和棋 0，全部自然结束
- `--auto --games 10 --seed 7`：虎胜 6 / 羊胜 4 / 和棋 0
- 伪终端交互冒烟：布子/走子/棋盘渲染/退出正常；非 tty 下中文提示并拒绝
- 无 TODO/FIXME 占位；`__pycache__` 已清理

## 诚实局限

- 双方 AI 只是 1 步贪心：熟悉规则的人类执任意一方通常能赢 AI。
- 采用"吃满 5 只虎胜"的常见规则；历史上各地规则细节（羊能否后退、
  虎吃子数等）略有出入，README 以本实现为准。
- 对局设 600 步上限防无限互绕，撞上限判和棋。
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+。
